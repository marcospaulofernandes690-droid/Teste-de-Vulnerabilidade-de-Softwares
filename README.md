## 📋 Sobre o projeto

O **Teste de Vulnerabilidade de Softwares** é um projeto de Trabalho de Conclusão de Curso voltado à área de segurança da informação.

O **SecPHP** é uma ferramenta de teste de vulnerabilidades para aplicações web em PHP, que usa a metodologia DAST (Dynamic Application Security Testing) para identificar automaticamente falhas críticas do OWASP Top 10 — como SQL Injection, XSS e RCE.

Problema que pretende resolver: muitas aplicações PHP ficam vulneráveis por falta de testes de segurança contínuos. O projeto permite detectar e corrigir essas falhas antecipadamente, evitando invasões e vazamentos de dados.
> **Importante:** os testes deverão ser realizados exclusivamente em sistemas próprios ou em ambientes nos quais exista autorização expressa para a realização das análises.

## 🔒 Uso responsável

Este projeto possui finalidade acadêmica e educacional.

A ferramenta não deverá ser utilizada para testar, acessar ou atacar sistemas sem autorização. Toda análise deve respeitar a legislação vigente, a privacidade dos usuários e as regras estabelecidas pelos proprietários dos sistemas analisados.

Os integrantes do projeto não incentivam a utilização da solução para atividades ilegais ou não autorizadas.
